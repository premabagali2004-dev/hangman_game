HANGMAN GAME (Python)

Requirements:
- Python 3

How to run:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code, or open a terminal in that folder.
3. Run: python hangman.py
   On some systems, use: python3 hangman.py

The game randomly selects one of five predefined words.
You can make up to 6 incorrect guesses.
